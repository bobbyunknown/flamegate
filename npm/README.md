# flamegate (NPM Package)

NPM wrapper distribution for **FlameGate** — self-hostable LLM proxy, intelligent router, and WebAssembly extension runtime.

## Installation

### Global Installation
```bash
npm install -g flamegate
# or
bun install -g flamegate
# or
pnpm add -g flamegate
```

### Run directly with NPX / Bunx
```bash
npx flamegate
# or
bunx flamegate
```

## Quick Start

1. **Bootstrap an API key**:
   ```bash
   flamegate bootstrap
   ```

2. **Start the gateway**:
   ```bash
   flamegate
   ```

3. **Open the dashboard**:
   Navigate to `http://localhost:20180` in your browser.

For full documentation, source code, and release notes, visit [FlameGate on GitHub](https://github.com/bobbyunknown/flamegate).
